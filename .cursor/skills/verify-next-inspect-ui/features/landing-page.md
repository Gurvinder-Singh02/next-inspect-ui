# Landing page

Use the site home at port 3000. Check the heading, Usage framework tabs, entry-file labels, code panels, and navigation links. Switch Next.js / React (Vite) and verify the selected tab and visible content.

The runnable helper is `../verify-landing-page.js`; run it with Bun from the repository root. `SITE_URL` overrides the site URL. It checks the site, not the separate component demo.
