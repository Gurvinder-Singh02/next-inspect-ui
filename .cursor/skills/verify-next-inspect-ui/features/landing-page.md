# Landing page

Use the marketing site home (`bun run dev`, default `http://localhost:3000/`). Check the heading, Usage framework tabs, entry-file labels in the selected tabpanel, code panels, and navigation links. With Next.js selected, the tabpanel must show `app/layout.tsx`. With React (Vite) selected, it must show `src/main.tsx`.

The runnable helper is `../verify-landing-page.js`; run it with Bun from the repository root. `SITE_URL` overrides the site URL. It checks the site, not the separate component demo.
