# Component gallery

Use `bun run dev:nextjs` and the printed URL, normally `http://localhost:3102/components`. Wait for the demo content. This app loads the inspector through the development `/inspect-ui.js` script, not a React `<InspectUI />` mount.

Click the page body, press Alt+X (or `Alt+KeyX`), hover a labeled demo control such as Activate Agent, then verify exact hover and Option-climb against `flow.md`. Read tooltip source with `textContent`. Capture the visible result. The marketing site does not serve this route.
