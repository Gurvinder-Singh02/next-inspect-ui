# test-vite-react

React 19.2.4 on Vite, without Next.js. Run `bun run dev:test-vite-react` from the repository root and open http://localhost:5173/test. Click Run all for exact node/source checks.


Fixtures cover HTML, SVG, shared buttons, memo, forwardRef, classes, and mapped children. React Server Components belong in the Next.js suites.
